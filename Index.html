💡 Why use MOD?

MOD gives the remainder. For size 5, (4 + 1) % 5 = 0 because 5 divided by 5 leaves remainder 0. Before the end, for example (2 + 1) % 5 = 3. It isn't needed for ordinary +1 unless wrapping is possible.

Learn the difference

GCSE → A-level

At GCSE, a list can hold several values. At A-level, consider how the queue is implemented: array capacity, insertion/removal cost, pointer changes, full and empty tests.

Static ≠ linear · Dynamic ≠ circular

Static/dynamic describes storage capacity. Linear/circular describes how the array positions are used. A circular queue can have a fixed array; a dynamic queue can be stored in a Python list.
